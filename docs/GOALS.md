# Bear Goals

## Goals

1. **Best-in-class launch speed** — less time from click to title screen  
2. **Modern developer experience** — clear APIs, great errors, first-class L support  
3. **Smooth runtime** — stable tick, predictable events, low overhead  
4. **Simple mod packaging** — one manifest, obvious entrypoints  
5. **Safe defaults** — version checks, dependency resolution, crash clarity  
6. **Extensible** — mixins/transforms as opt-in layers, not required for basic mods  

## Non-goals (v1)

- Replacing every Fabric/Forge feature on day one  
- Supporting ancient Minecraft versions  
- Forcing L — Java/Kotlin mods stay welcome  
- Shipping a full launcher (Bear is a **loader**, not a launcher)

## Success metrics

- Cold start overhead competitive with or better than current loaders  
- New mod author productive within minutes  
- Crash reports that name the offending mod and phase  
- L mods compile and load without extra glue
